# Changing how it looks (for the school owner)
Edit files on GitHub: open the file, click the pencil icon, change it, click **Commit changes**. A green tick appears under **Actions** within a minute or two.

| To change | Open this file |
|---|---|
| Colours, corner roundness, fonts | `docs/css/theme.css` (the values at the top) |
| School name and tagline | `docs/js/config.js` |
| Friendly names for fee items | `LABELS` near the top of `docs/js/app.js` |
| Crest image | replace `docs/img/logo.png` (same file name) |
| App icons | files in `docs/icons/` |

Fonts (Fraunces, Manrope, IBM Plex Mono) come from Google Fonts under the SIL Open Font License.
